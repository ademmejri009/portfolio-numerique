Prompt engineering

Les éléments d'un bon prompt

Rôle, contexte, tâche, format de sortie, contraintes, exemples.

Techniques

  • Raisonnement étape par étape
  • Fournir des exemples
  • Itérer et affiner
  • Demander une vérification

Cas pratique 1 : expliquer le phishing

ÉlémentContenu
Prompt initial (faible)« Parle-moi du phishing. »
Résultat obtenuRésultat typique : longs paragraphes encyclopédiques, sans exemple concret ni structure.
Prompt amélioré« Tu es un expert en cybersécurité qui s'adresse à des étudiants de 1ère année. Contexte : je prépare une page de portfolio. Tâche : explique le phishing. Format : définition en 2 phrases, 3 signes pour repérer un faux message, 3 réflexes. Contraintes : moins de 150 mots, français simple, sans jargon. »
Résultat obtenuRéponse obtenue (91 mots, sous la limite de 150) : « Le phishing (hameçonnage) est une arnaque où un faux message se fait passer pour un organisme de confiance afin de voler vos identifiants ou votre argent. Il arrive par e-mail, SMS ou réseaux sociaux. Trois signes : 1) une adresse d'expéditeur bizarre ; 2) un ton pressant ou menaçant (« compte bloqué sous 24 h ») ; 3) un lien ou une pièce jointe inattendus. Trois réflexes : 1) ne pas cliquer ; 2) aller directement sur le site officiel en tapant son adresse ; 3) signaler et supprimer le message. »
AnalyseCe qui a changé : le rôle, le contexte, le format et les contraintes ont remplacé une demande vague. Le résultat est plus court, plus ciblé et vérifiable point par point.

Cas pratique 2 : comprendre une erreur de code (langage C)

ÉlémentContenu
Prompt initial (faible)« Mon code C ne marche pas, répare-le. »
Résultat obtenuRésultat typique : l'IA renvoie directement un programme corrigé, sans expliquer l'erreur. Je ne comprends pas ce qui était faux, ce qui va à l'encontre de la règle d'or n°6.
Prompt amélioré« Voici mon code C (4 lignes) et le message de gcc : format '%d' expects argument of type 'int *', but argument 2 has type 'int' [-Wformat=] N'écris pas la solution complète. Explique-moi ce que signifie le message, indique la ligne concernée et donne-moi un indice. »
Résultat obtenuRésultat typique : l'IA explique que scanf doit écrire dans la variable, donc recevoir son adresse (&n) et non sa valeur ; elle désigne la ligne 4 et propose un indice sans donner le code final.
AnalyseCe qui a changé : en fournissant le message d'erreur réel et en ajoutant une contrainte (« n'écris pas la solution »), j'obtiens une explication et je corrige moi-même. Le message gcc est reproduit tel quel : c'est un vrai résultat de compilation.

Cas pratique 3 : réviser un cours

ÉlémentContenu
Prompt initial (faible)« Résume mon cours sur les systèmes d'exploitation. »
Résultat obtenuRésultat typique : texte flou et sans lien avec mon cours.
Prompt amélioré« Voici mon cours (collé ci-dessous). Raisonne étape par étape : 1) liste les 10 notions clés ; 2) présente-les en un tableau notion / définition ; 3) pose-moi 5 questions de quiz sans les corrections ; 4) vérifie à la fin ce dont tu n'es pas sûr et dis-le-moi. »
Résultat obtenuRésultat typique : 10 notions classées dans un tableau, 5 questions de quiz, puis une courte liste de points à vérifier dans le cours.
AnalyseCe qui a changé : technique du raisonnement étape par étape, format de sortie précis et demande de vérification. Le quiz me sert à m'entraîner au lieu de relire passivement.

Note : le cas 1 (version améliorée) est une vraie réponse de Claude ; les résultats des cas 2 et 3 sont des résultats typiques, sans capture.

Bibliothèque de prompts

  1. « Tu es un tuteur patient. Explique [notion] à un étudiant de 1ère année avec un exemple concret, puis pose-moi 3 questions pour vérifier ma compréhension. »
  2. « Voici mon code et le message d'erreur. N'écris pas la solution : explique-moi ce que signifie l'erreur et où chercher. »
  3. « Résume ce cours en 10 points clés, puis propose un quiz de 5 questions. »
  4. « Relis ce texte : signale les fautes et les phrases floues, sans réécrire à ma place. »
  5. « Donne-moi 3 sources fiables sur [sujet], avec lien, et indique ce que chacune apporte. »
